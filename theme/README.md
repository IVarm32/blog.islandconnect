# Island Connect AI WordPress Theme

This folder contains the standalone WordPress theme derived from the Island Connect AI website.

## WP Pusher Setup
1. In WordPress, go to **WP Pusher > Themes**.
2. Install from GitHub: `IVarm32/blog.islandconnect`.
3. Set the **Subdirectory** to `theme/island-connect`.
4. Enable **Push-to-Deploy**.

The theme is pixel-perfect and includes "The Loop" in `index.php` for dynamic WordPress content.
